# Brand Sign — Creative Marketing Agency Website

A minimalist, luxury, conversion-focused agency website for **Brand Sign** (`CREATIVE MARKETING AGENCY`), specializing in:

1. **Product Photography**
2. **Poster Design**
3. **UGC Ads**

## Design & Brand Specifications

- **Palette**: Pure gallery white (`#FFFFFF`), warm alabaster (`#FAF9F6`), deep obsidian black (`#0A0A0A`), and subtle ash-gold (`#B09A76`) accents.
- **Hero Headline**: *“Turn Ads Into Paying Customers.”*
- **Direct Contact & Socials**:
  - **Email**: `services.brandsign@gmail.com`
  - **Instagram**: [`@brandsign.products`](https://www.instagram.com/brandsign.products?dlrf=MW1sdDRuamZlZ2xyYQ==)
  - **Facebook**: [`Brand Sign Official`](https://www.facebook.com/share/19dYk6CtXd)
- **Google Drive Project Archive**: Pre-loaded with all **35 client project images** and the official **Brand Sign** logo from the Google Drive `Brand` folder.
- **Replaceable Project Image Placeholders**:
  - Every image slot in the **Hero**, **Services**, and **Portfolio** sections is designed as a replaceable placeholder.
  - Click `⟳ Replace Image` on any frame (or drag and drop a JPG/PNG onto any project card) to upload new client work directly in the browser.
  - Switch between **B&W Luxe Hover** (monochrome + subtle ash-gold tonal gallery grade that reveals full studio color on hover), **Studio Color**, and **Placeholder Slots** (explicit architectural wireframe placeholders).

## Running Locally

```bash
npm start
# Opens at http://0.0.0.0:3000
```
